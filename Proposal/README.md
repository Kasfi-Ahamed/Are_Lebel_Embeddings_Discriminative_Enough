# Proposal

This folder contains proposal-stage materials for the SIT770 NLP project on label embedding discriminativeness in zero-shot intent detection.

## Contents

```text
Proposal/
├── Notebook/
├── Outputs/
└── README.md
```

## Purpose

- Keep proposal experiments and early evidence separate from final main research runs.
- Preserve proposal notebook outputs and figures used in submission/reporting.

## How To Use

1. Open files under `Proposal/Notebook/` for proposal analysis.
2. Use `Proposal/Outputs/` for generated figures and tables.
3. Commit proposal updates independently from `Main Research` when possible.

## Git Notes

- Prefer small commits scoped to one proposal update at a time.
- Include short commit messages that describe the proposal change intent.
