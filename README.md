# SIT770 NLP Research Repository

This repository contains the project materials for the SIT770 NLP study on label embedding discriminativeness in zero-shot intent detection.

## Repository Structure

```text
.
├── Main Research/   # Full research experiments and outputs
└── Proposal/        # Proposal-stage notebook, figures, and write-up assets
```

## Folders

- `Main Research`: Final/extended experiment notebook, generated figures, and dependency file.
- `Proposal`: Proposal notebook and supporting outputs for early-stage reporting.

## Quick Start

1. Create and activate a Python virtual environment.
2. Install dependencies from `Main Research/requirements.txt`.
3. Open the notebook in `Main Research/Notebook/` and run cells in order.

## Notes

- Large result artifacts are kept inside each project folder.
- Commit notebooks and output updates with clear messages for easier tracking.
