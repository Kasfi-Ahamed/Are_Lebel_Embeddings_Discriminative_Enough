# Main Research

This folder contains the primary experiment notebook and outputs for the SIT770 NLP research project.

## Contents

```text
Main Research/
├── Notebook/
│   └── label_embeddings_experiment.ipynb
├── outputs/
└── requirements.txt
```

## What Is Here

- `Notebook/label_embeddings_experiment.ipynb`: Main end-to-end experimental workflow.
- `outputs/`: Saved plots, tables, and derived files generated by notebook runs.
- `requirements.txt`: Python dependencies used for this research environment.

## How To Run

1. Create and activate a virtual environment.
2. Install dependencies:
   - `pip install -r "Main Research/requirements.txt"`
3. Run the notebook in `Main Research/Notebook/`.

## Git Guidance

- Keep notebook outputs intentional before committing.
- Group code logic changes and result updates in meaningful commits.
